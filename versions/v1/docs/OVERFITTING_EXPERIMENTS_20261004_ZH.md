# ROI32 过拟合控制与损失消融实验方案

日期：2026-10-04。目标：`/root/autodl-tmp/line b/breast-mri-vla-jepa`。

本文件保留最初的实验设计。A1/A2 已完成，逐种子结果见 A1/A2 汇总（未随源码发布的历史工件：`../reports/A1_A2_RESULTS_20261004_ZH.md`）；L1-L4 已实施，共16次新训练，具体固定策略、诊断、启动与恢复见 [L系列执行说明](L_LOSS_EXPERIMENTS_20261004_ZH.md)。原 A0 与选定 A* 结果继续保留为对照。下列候选不因已实施就代表已证实有效。

## 现象与原因判断

### pCR过拟合有直接证据

最佳轮时训练BCE约0.52–0.55，验证选模NLL约0.53–0.57；停止时训练BCE降到0.12–0.26，验证NLL升到1.24–1.80。四组都表现出明显训练/验证分离。

恶化不止体现在NLL。对同一验证患者集合，从最佳到最终：

| 版本/种子 | 验证T0 AUROC | 验证T0 Brier | 验证选模NLL |
|---|---|---|---|
| 固定T0/17 | 0.7357 -> 0.6397 | 0.1776 -> 0.2891 | 0.5329 -> 1.3507 |
| 固定T0/43 | 0.7406 -> 0.6674 | 0.1794 -> 0.2688 | 0.5383 -> 1.2384 |
| 动态/17 | 0.7112 -> 0.5987 | 0.1900 -> 0.3410 | 0.5590 -> 1.4523 |
| 动态/43 | 0.7290 -> 0.5862 | 0.1873 -> 0.3629 | 0.5665 -> 1.8011 |

动态选模NLL包含所有合法阶段，表中AUROC/Brier只取T0。动态seed17的T3 AUROC最后略高于最佳轮，因此不能概括为每个阶段的排序指标都下降。

NLL对高置信错误很敏感。例如真实pCR=1时，预测概率从0.1降到0.01，单病例NLL从2.30增到4.61。因此继续拟合训练患者、对验证错误变得更确信，可以导致NLL大幅上升。当前未保存全程逐病例概率，无法量化这种机制的贡献；AUROC也下降，说明不能只靠事后校准恢复全部性能。

可能促成因素包括764名独立训练患者下持续拟合、恒定LR1e-4、现有dropout0.1和weight_decay0.01的正则强度，以及辅助目标与分类目标之间的作用。3039次检查不等于3039个独立pCR患者。这些因素的因果贡献需要对照实验确定。

### JEPA回升不能直接等同于世界模型过拟合

已乘0.5的JEPA从首轮约0.34降到最佳pCR轮附近的0.10–0.13，最终回升到0.20–0.25，仍低于首轮。JEPA记录的是训练teacher-forcing目标，当前没有逐轮的独立世界验证指标。

编码器持续受pCR/重构等目标更新；EMA教师随之更新，因此JEPA每轮的源和目标状态也在改变。EMA decay=0.995约对应200次更新的平滑尺度，以每轮48次更新计约4轮。这是时间尺度解释，不是“EMA延迟导致损失回升”的实验证明。

可能机制包括目标特征的尺度/坐标变化、预测头跟踪不足、动态条件变化、任务竞争或真实转移监督困难。此前最佳checkpoint抽样中，加权JEPA的encoder+fusion梯度仅为pCR的0.6%–3.4%，大部分进入私有world_predictor；这不足以认定JEPA过强。重构共享梯度两批均值约为pCR的21%–52%，值得优先消融。

未verified的配准转移不是已证明配准失败。它们的噪声贡献要通过独立的世界监督质量实验验证。

### 已知实现问题与结构判断

现有方差惩罚把患者/检查与空间token一起统计，患者相同的表征可以靠位置差异满足约束。它需要修正，但尚未证明正式模型塌缩，也未证明它是过拟合的唯一原因。

已有损失、总梯度均有限，教师冻结，未发现普通pCR读未来真实影像/标签。因此先保持dim128、网络深度和2x4x4网格，测试训练策略与损失贡献。若充分正则后的纯监督模型仍差，再考虑容量、预训练和输入信息来源。

## 统一协议

- 患者、影像、三相顺序、ROI32尺寸和现有图像标准化保持一致：764 train /102 development val，test为空。
- 每个神经网络设置均做固定T0与all_observed两版，各seed17/43，即4次训练；不能按种子分别选超参。
- 物理batch16、accumulation1、CUDA BF16训练、FP32验证、最大200 epoch、patience50、min_delta0、clip1.0、AdamW。保持原患者级排列和动态合法阶段采样方式。
- 固定版按T0 NLL选best，动态版按患者内合法阶段平均NLL再对患者平均选best。保持全合法未来query模式，不在此实验中改变query mask接口。
- 选模以原NLL为主，报告所有种子的AUROC/AUPRC/NLL/Brier、最佳/停止轮次。动态分别报告T0–T3及各阶段人数，不用最高AUROC重选checkpoint。
- 每个实验从相应种子的相同初始模型重新训练，使用独立输出目录。原best/last仅保留和复核；改变训练配置或源码后不恢复旧run。
- patience50用来维持原控制变量。后续可统一改为15节省计算，但须形成新的共同协议；它不能单独作为“解决过拟合”的证据。

## 第一轮：控制过拟合

原完整损失保持不变：BCE +0.5 JEPA +0.1重构 +0.01原方差。

| ID | 优先级 | 唯一改动 | 固定参数 | 回答的问题 |
|---|---|---|---|---|
| A0 | 已完成参考 | 无 | 恒定LR1e-4，dropout0.1，WD0.01 | 原始泛化退化轨迹 |
| A1 | 首轮必做 | 增加ReduceLROnPlateau | mode=min，factor0.5，patience5，min_lr1e-6，threshold0/abs；其他同A0 | 验证停滞后减小更新，是否改善最佳泛化并减轻后期恶化 |
| A2 | 首轮必做 | dropout0.1 -> 0.3 | 恒定LR1e-4，WD0.01，原完整损失 | 增强现有网络的正则化是否有效 |
| A3 | 条件性后续 | WD0.01 -> 0.05 | 恒定LR1e-4，dropout0.1，原完整损失 | 如果A1/A2仍不够，参数收缩是否有效 |

A1在每轮验证结束后，用该版本的原选模NLL调用scheduler；scheduler、早停和严格最低best分别保留自己的状态。记录每轮LR并将scheduler状态写入checkpoint，验证续训一致。保持pCR/world/重构各模块原学习率分组方式。

A2改变现有全局dropout字段，涉及编码器、融合层和世界预测器的Transformer；它是明确的全局dropout实验。若希望只提高pCR头dropout，作为后续独立结构设置，不能混入A2。

首先做A1/A2，共8次新训练。先不叠加scheduler、dropout和WD。根据每版两种子的平均最佳选模NLL与辅助指标选共同训练设置A*；种子结论不一致时标注不稳定，不能只汇报改善的种子。若A1/A2都改善，后续可加一个二者组合的确认设置，不能将组合改善归因到单个因素。

成功标准：最佳验证NLL较A0改善，同时检查AUROC/AUPRC/Brier是否发生不利权衡，并观察后期eval训练/验证差距。只把最终NLL压低、或把训练与验证同时变差而缩小差距，不能作为成功。102人开发集上的反复择优不构成独立泛化证明。

## 第二轮：逐项检验损失

所有设置固定为相应版本的A*训练策略，保持模型、输入、样本、优化器和验证协议一致。L0直接使用A*中原完整损失的结果。

| ID | 设置 | pCR权重 | JEPA权重 | 重构权重 | 方差权重/定义 | 对照及解释 |
|---|---|---:|---:|---:|---|---|
| L0 | 原完整损失 | 1 | 0.5 | 0.1 | 0.01 /原定义 | 已有A*结果，可复用 |
| L1 | pCR-only | 1 | 0 | 0 | 0 /关闭 | 纯监督锚点；与L0的差异不能归因到某一辅助项 |
| L2 | 去重构 | 1 | 0.5 | 0 | 0.01 /原定义 | 相对L0只移除重构，优先检验粗重构是否牵制表征 |
| L3 | 去JEPA | 1 | 0 | 0.1 | 0.01 /原定义 | 相对L0只移除JEPA，检验其分类贡献 |
| L4 | 修正方差 | 1 | 0.5 | 0.1 | 0.01 /患者轴定义 | 相对L0只改方差统计定义，检验真正患者级约束 |

L1–L4共16次新训练。第一、第二轮初始总计24次新神经网络训练；已完成A0和选出的A*均复用。条件性组合、A3、后续权重扫描及输入对照不在这24次里。

方差修正：将在线编码特征放回[B,4,N,C]，对同阶段、同token、同通道在有效患者轴计算FP32方差，unbiased=false、epsilon1e-4、std目标1.0；只用合法已观察输入，阶段有效患者少于2时跳过，对有效阶段平均。不能将同一患者的多个检查或不同空间位置充当独立患者。记录各阶段有效人数、原/新方差值与患者池化特征的有效秩。L4先保持系数0.01不变以隔离定义；是否需要更合适的幅度另做后续实验。

结果解释：L2优于L0支持移除或重新设计重构；L3优于L0提示当前JEPA未提供pCR收益；L1优于L0表明整组辅助目标未带来分类收益。若L3不影响pCR但JEPA确实改善自主预测，可为世界学习目标保留它。任何一个设置恶化，都要报告相应种子，不只保留正向结果。

若L2与L4分别支持去重构/修正方差，再追加一个确认设置L5：BCE +0.5 JEPA +0.01患者轴方差。它与L4只差重构，与L2只差方差定义，不同时换解码器。是否将其作为新主模型由结果决定。

## 第三轮：诊断驱动的条件性实验

### JEPA与copy的独立评价

不需要再训练一个copy网络。对所有训练过JEPA的checkpoint，在相同合法起点、终点和患者集合上计算：

- teacher-forcing一步L1：每个转移使用真实前驱状态；其copy基线为真实前驱保持不变。
- 自主1/2/3步L1：预测仅使用合法历史，递归使用自己的预测；其copy基线在全部未来步保持起点状态。
- 按患者先平均，再跨患者平均；报告预测/对应copy误差比及skill=1-该误差比。误差比小于1表示数值上优于copy，copy接近0的情况单列。
- 主分析采用真实连续访视链，缺T1不能被拼成T0->T2的一步。存在起点和远期终点但缺中间真实检查的自由预测，作为缺失随访补充分析单列。
- 全队列与verified质量子组分别报告。QC仅用于监督或统计分层，不能进入普通pCR输入、输出query选择或推理条件。
- 每个checkpoint的教师在评价时冻结。不同checkpoint的原始latent L1不是同一特征坐标，要结合copy比、患者级方差、有效秩和未来表示质量解读，不能只按raw L1排名。
- JEPA关闭组的world_predictor未训练，不将其随机预测当成有效世界学习方法。

另在固定训练probe上每5轮记录教师特征尺度、相邻访视copy L1、教师相对上次probe的特征漂移，以及teacher-forcing/自主预测误差。

| 观察 | 支持的解释 | 下一步 |
|---|---|---|
| 教师尺度或copy误差升高，预测/copy比稳定 | 标尺/目标变化参与JEPA回升 | 先评估固定/归一化目标的独立设置；不直接把raw L1升高视为质量退化 |
| 训练世界误差改善，固定验证世界误差变差 | 支持世界预测头过拟合 | 单独正则预测头或冻结表征对照 |
| copy较稳定，预测/copy比明显恶化 | 支持预测器或动态条件跟踪退化 | 检查目标漂移与各模块梯度，再比较JEPA权重 |
| teacher-forcing尚可，自主多步明显变差 | 支持递归误差积累/训练推理差异 | 独立比较多步训练目标或rollout训练 |
| L1/copy很小，但患者方差/有效秩也很低 | 潜在表征塌缩 | 先处理患者级表征约束，不能宣称预测成功 |

JEPA权重需要扫描时，固定选定的其他损失和训练设置，比较0、0.1、0.5。0组回答分类贡献，非零组同时评价自主未来预测。先不加入自动权重平衡、PCGrad或改变EMA系数；只有固定probe显示持续冲突或目标漂移证据后再单独验证。

### 重构形式与转移质量

若移除重构有利，先用现2x4x4输出与相同网格的粗目标比较，保留原重构为对照；不要同时改网格/解码器/损失权重。小解码器作为更后面的独立结构实验。

若world评价提示质量子组差异，再比较全部转移与仅verified的JEPA监督，保持所有pCR患者和原预测输入不变。训练1865个相邻转移只有201个verified，监督覆盖减少本身也是实验因素；必须报告覆盖，不将verified小组外推为总体。

### MRI与临床+Arm信息对照

在L1纯pCR训练设置下单独做MRI-only，临床值与mask及Arm全部按合法缺失状态关闭，保持MRI主干和其余协议；与L1只差输入信息。

临床+Arm使用独立L2 logistic基线，age/HR/HER2/MP和缺失指示、Arm类别编码，C=1.0预先固定。训练统计仅来自训练患者；不使用MRI、未来检查是否存在或阶段输出query。基线只有T0可用静态字段，因此同一患者跨阶段预测保持相同，阶段指标仍按实际合法检查患者集合计算。确定性拟合不需要重复两个随机种子。Arm仍标明assigned_arm_scenario假设。

如果临床+Arm接近完整MRI模型，支持进一步检查MRI的增量收益；若MRI-only比联合模型更稳定，再分析临床/Arm利用与分布。它们不与loss消融混在同一个改动中。

## 新训练需要的最小工程准备

1. supervised one_stage允许JEPA/重构/方差为0；representation-only另检查非零表征目标。当前train_config.py强制重构/方差为正，L1/L2暂不能直接运行。
2. 增加显式none/plateau scheduler选项、每轮LR日志与checkpoint状态；按原selection_score调度。连续训练和中断恢复比较采样顺序、LR、模型/EMA和最佳轮次。
3. 增加患者轴方差选项，保留原定义以复现L0–L3。测试患者完全相同/空间位置不同的反例，缺失随访、阶段仅1人、末批12和FP32/BF16稳定性。
4. 实现固定probe的train-eval pCR NLL、分项加权梯度/模块范数、方向余弦、clip比例、参数更新范数，以及world/copy指标。训练中诊断必须保存/恢复RNG、train/eval状态，不更新参数/EMA，不改下一批任务或dropout序列。
5. pCR-only跳过未使用的世界目标影像读取和分支计算，仍独立读取pCR标签并保留四槽/因果边界。监测优化不能通过删除输入mask检查来实现。
6. 运行原完整测试和上述新增回归；两版合成smoke、真实B16 CUDA BF16短程确认有限梯度、教师无梯度和调度续训一致，随后才开始正式矩阵。
7. 新源码使用独立协议和输出。当前三个并发授权可用于后续队列，但实际启动前按新的显存测试结果确定；本设计尚未启动队列。

## 报告与决策

每个设置交付逐种子指标、完整训练曲线、实际LR、clip率、辅助梯度/方向、world/copy与特征尺度/有效秩。最佳checkpoint与最后checkpoint分开报告。主要判断是否改善原best验证性能，不能把“最后没有继续变差”代替模型效果提升。

开发集患者配对bootstrap可用于描述差异，动态重采样单位必须是患者，保留其全部合法阶段。102人已反复用于调参/选轮，其区间不消除模型选择偏差。需要新独立患者测试或预先规定的严格患者级验证协议，才能声称泛化问题得到解决。若进一步做内层划分，临床等可拟合统计需按内层训练重拟合；现冻结ROI32影像统计来源是全部原764训练患者，严格每折重拟合图像处理需回到上游，不能直接宣称现缓存是完整无泄漏的内层流程。

证据：完整训练诊断（未随源码发布的历史工件：`../reports/training_process_20261004/REPORT_ZH.md`）、原逐种子结果（未随源码发布的历史工件：`../reports/EPOCH200_RESULTS_20261004_ZH.md`）、代码审查（未随源码发布的历史工件：`../reports/CODE_REVIEW_20261004_ZH.md`）。

推荐执行顺序：A1/A2 -> 固定A* -> L1/L2/L3/L4 -> 独立world/copy判读 -> 按证据追加L5、JEPA权重或重构/输入对照。第一轮不同时更改网络、损失和数据筛选。
