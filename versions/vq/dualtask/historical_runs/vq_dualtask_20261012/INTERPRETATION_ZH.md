# 双任务实验：完成结果与解释

2026-10-12，北京时间 16:05，六次训练和十二份完整开发验证集的状态评价全部完成，自动严格分析通过。两项任务是直接 pCR 分类与未来潜在状态预测；它们共同训练共享编码/融合网络，但预测状态不回送 pCR 头。本实验不生成 MRI 像素。

所有模型使用 `BCE(pCR) + 0.5 × JEPA latent L1`，重构、flow、方差正则关闭。dynamic 输入、种子 17/43、batch 16、accumulation 1、dropout 0.3、网络学习率 1e-4，最多 200 epoch、patience 50 epoch。冻结 A 从旧 codec 前端重新开始；微调 B 继承匹配的新 A 完整 best，前端学习率 1e-5，新优化器与采样器。两组 A→B 的完整 201 个模型张量初始化重放一致，实际运行也验证了两个学习率。

六组均正常早停，退出码为 0；原 V1 与已完成的 VQ pCR-only 实验的 368 / 127 个受保护文件未变化。最终没有训练/评价进程存活，GPU 已空闲。工程核验见 完成记录（未随源码发布的历史工件：`../../reports/vq_dualtask_completion_20261012.json`）；数字和逐种子差值见 完整聚合（未随源码发布的历史工件：`analysis.json`） 与 [完整结果表](RESULTS_ZH.md)。

在相同原始 CNN 上加入 JEPA，整体 pCR 尚未获益：平均 NLL 比原 L1 高 0.004456，seed17 变差、seed43 略好；T1 AUROC 两种子均提高，其他阶段没有一致改善。不能把单阶段 AUROC 上升等同于总体分类改善。

在冻结 VQ 上加入 JEPA，pCR 有一致的 NLL 改善：seed17/43 相比旧冻结单任务分别降低 0.013438 / 0.019814，平均降低 0.016626。四阶段 AUROC 均值也提高。但新冻结 VQ 的 NLL 仍高于新 CNN 双任务及原 L1，当前没有证明替换 VQ 前端能取得更好的 pCR。

小学习率微调没有进一步改善 pCR 主指标 NLL。B17/B43 相比自己的 A-best，NLL 分别上升 0.007600 / 0.004564；两种子平均从 0.566432 上升到 0.572514。B 的 T0 AUROC 均值略升，其他阶段与指标有混合变化。新 B 优于旧 pCR-only B 的平均 NLL，但两组 B 继承不同的 A 起点，不能据此单独归因于微调阶段的 JEPA。B 还获得额外训练预算，比较时需保留这一差别。

世界任务用每个 checkpoint 自身 EMA teacher 的真实目标，比较 teacher forcing 与 1–3 步自主预测。自主 copy 固定起点真实状态，TF copy 使用真实前一期。下面是两种子各自 `模型 latent L1 / copy latent L1` 的算术均值；小于 1 表示在该模型自身坐标里优于复制基线。

冻结和微调 VQ 的 pCR-best 都有实际的状态预测价值：两个种子的 TF 及自主各 horizon 均优于各自 copy。CNN 的 pCR-best 在两个种子的相邻 TF 和自主全步指标上均未超过 copy；自主 3 步均值略低于 1，但仅一个种子超过 copy。各方案的 last 在两个种子的自主各 horizon 均超过各自 copy。

不同模型和 best/last 的 teacher 会变化，这些 latent 任务没有共同坐标；不能直接排名原始 latent L1，也不能把不同模型的 ratio 排名解释为同一目标空间上的生成能力排名。pCR-best 不是世界任务最佳权重，本实验也没有按世界指标选择 world-best。末轮比值较低不意味着与早期 teacher 完全相同任务上的进步，更不代表末轮分类更好。

动态验证的 T0/T1/T2/T3 分类人数为 102/100/94/86。自主 horizon 1/2/3 分别覆盖 102/92/84 名患者和 278/176/84 个前缀目标；要求真实连续访视，不补造缺失中间状态。全步为 102 名患者、538 个前缀目标；相邻 TF 另包含较早访视缺失后的真实相邻转移，共 540 个前缀转移。先在患者内部平均，再平均患者。

本次已完成“两个任务实际训练并分别评价”。证据支持冻结 VQ 上的辅助 JEPA 能改善此前 VQ 分类结果，也支持 VQ 模型在各自 latent 任务中超过 copy；证据尚不支持 pCR 超过原 L1，或微调能进一步改善 pCR。六组末轮分类均明显过拟合，使用 best 进行 pCR 比较。

这些结果来自重复使用的 102 人开发验证集、两个随机种子，测试集人数为 0。它们是该开发协议内的实验结果，不是独立测试表现，也没有显著性或临床效用结论。
