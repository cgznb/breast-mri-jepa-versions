## 已确认的问题与待验证机制

六次训练最佳轮之后均出现训练 fused BCE 下降而验证 NLL 上升。动态 seed17/43/71 的 best→last 验证 NLL 分别为 0.591→1.761、0.606→1.963、0.615→1.463；固定 T0 也退化，但程度较轻。训练 BCE 是 dropout 开启且参数不断更新的轮内均值，不等于同一 checkpoint 的静态训练集风险。

最佳权重的临床效果也弱于旧主线。因此目标是改善患者级验证预测，并限制后期退化；缩小曲线间距本身不能证明算法更好。

## 推荐第一版算法

### 1. 保留前缀 sample，按患者等权优化

设训练患者数为 N，患者 i 有 K_i 个合法前缀，总前缀数 M=ΣK_i。每个前缀仍作为一个 sample，每个完整 epoch 全部遍历。给每行固定权重：

`w_i = M / (N × K_i)`

逐样本目标按下式定义：

`J_add = (1/N) Σ_i (1/K_i) Σ_k [L_masked(i,k) + L_B(i,k) + L_C(i,k) + λ(u)L_cons(i,k)]`

等价于在 M 个前缀上取 `w_i × loss` 的全局平均。完整四前缀患者的每个 sample 权重是两前缀患者的一半；两名患者的总目标系数相同。固定 T0 的 K_i=1，所以 w_i=1。

具体归约：

- masked latent L1 先平均当前 sample 的被遮蔽 token 与通道，保留一个样本损失；不能先平均整个 batch 再补权重。
- TF / free rollout 先平均该 sample 的有效未来目标，然后乘 w_i。没有未来的 T3 sample 的 B 损失为 0；不按每批有未来的人数重新归一化。
- fused/direct/forecast BCE 以及一致性项均先保留逐样本值，再乘 w_i。
- 梯度归约使用固定参考分母 batch_ref=16，即 `Σ_batch w_i ℓ_i / 16`，尾批不因人数少而放大单个患者；累积与超出参考大小的合法尾批按实际权重求和。完整 epoch 的日志按 `Σ_all w_i ℓ_i / M` 独立计算。在固定参数下，各 sample 对 epoch 梯度和的系数由 w_i 决定。分阶段组批的有限 batch SGD 仍是近似优化，不能宣称每个更新都是患者风险的无偏估计。
- 禁止每 batch 再除以 `Σ_batch w_i`。这种自归一化结合阶段组批，会改变患者之间原定的相对权重。

方差、协方差和 token 方差属于 batch 统计，单独定义：

`J = J_add + L_variance + 0.04 L_covariance + 0.1 L_token_variance`

保持现有同 anchor 阶段、不同患者的物理 batch 统计，不把一个 batch 协方差标量广播后冒充逐患者等权。第一版只对可加的逐 sample 项建立精确数据集目标；这些 batch 正则的患者展示次数仍随前缀数变化。若对照表明此问题关键，再单独测试按患者抽样的 A 正则支路。

### 2. 截断未来分类到终末特征的直接梯度

推荐版设 `forecast_detach=true`：

`p_forecast = Head_forecast(stop_gradient(z_T3), clinical, arm, landmark)`

世界模型继续由 TF 和 free rollout 学习；未来分类头、直接头、融合门控继续由 pCR 学习。共享编码器 / 融合主干也继续接受直接分类梯度，ABC 仍在同一步联合更新。

这只切断 `pCR → forecast terminal → world` 的直接路径。临床 / 阶段嵌入、共享 fusion、online encoder 和经 EMA 更新的 teacher 仍会受到分类训练的间接影响，直接 pCR query 也能读取转移 query。不要将这一开关称为完全隔离世界表征。是否有收益必须由 detach 单因素实验验证。

若确实需要完全标签隔离，另设更强对照：共享世界骨干只接收 A+B 梯度，world 只接收 B 梯度，分类专属 query / heads / terminal_pool / gate 只接收 C+consistency 梯度，使用明确的分损失梯度路由。这个版本限制任务微调，可能欠拟合，不属于第一版默认改动。

### 3. 同一前缀的两次随机预测一致性

同一患者、同一 landmark、同一合法 MRI / 临床 / 治疗输入，使用独立 dropout mask 前向两次，得到 p1、p2。两次均使用相同真实 pCR 标签：

`L_C = 0.5 × [L_C(view1) + L_C(view2)]`

其中每个视图的 `L_C = BCE_fused + 0.5 BCE_direct + 0.25 BCE_forecast`。一致性先只约束融合概率：

`L_cons = 0.5 × [KL(Bern(p1) || Bern(p2)) + KL(Bern(p2) || Bern(p1))]`

所有概率和补概率的 KL 用稳定的 log-sigmoid / logits 计算，并在 FP32 归约；极端 logit 下也应有限。两个分支对称反传，未来 latent 的梯度仍按上述 detach 规则处理。这里采用同输入 dropout 一致性（R-Drop），当前 EMA encoder 不具备分类预测头，不能当作已有的分类 Mean Teacher。

第一版起始设置：dropout 保持 0.1，`λ(u)=0.1×min(u/500,1)`。0.1 和 500 updates 是预先指定的待验证起点，没有声称是最优值。A 和 B 仅在第一个视图计算一次，避免无意将它们的权重翻倍；两次分类前向增加算力成本，需要同时报告耗时。

该约束要求相同条件下的随机预测稳定，不要求同一患者 T0/T1/T2/T3 的预测相等。新检查可以改变患者的 pCR 风险估计。

### 4. 用优化更新数定义训练进度

首次机制试验采用统一起始协议：

| 参数 | 起始设置 |
|---|---|
| 网络容量 | 维持当前结构 |
| 训练模式 | ABC joint，从随机初始化 |
| 动态 sample | all_prefixes；同批患者不重复、actual anchor 相同 |
| batch / accumulation | 16 / 1 |
| 优化器 | AdamW，head LR1e-4、backbone LR3e-5、weight decay0.01 |
| 学习率调度 | warmup200 updates，随后 cosine，最低比例0.05 |
| 最大预算 | 3000 optimizer updates |
| 验证频率 | 每100 updates，首次评估更新前模型，并在结束时评估 |
| 早停 | NLL 连续500 updates未改善；min_delta1e-5 |
| checkpoint选择 | 原始标签上的患者等权 fused NLL |
| 教师 | 每次 AdamW 后 EMA0.996，教师无反向梯度 |
| 原任务权重 | masked1、variance1、covariance0.04、token_variance0.1、TF0.25、rollout1、fused1、direct0.5、forecast0.25 |

固定和动态都用以上更新计数作同预算敏感性对照，但两者可见历史不同，不能仅以固定 / 动态差值归因某个算法组件。all_prefixes 的患者加权不会减少实际前向次数或独立患者相关性。

这些调度参数不同于已完成六次的 epoch 调度。因此必须重新运行相同新协议的 baseline；已有六次只作历史参照，不能替代单因素对照。无需先增加 A-only 预训练或改变骨干容量。若第一版仍显示表征学习不足，再独立检验 A warm-start；当前 joint 的 `--init` 明确拒绝 warm-start，需要新增实现，旧主线编码器权重也不能直接加载。

## 最小验证矩阵

所有新实验共享初始化种子、患者划分、基础学习率和更新 / 验证预算。首先针对动态训练做机制筛选：

| 编号 | 患者等权 | forecast detach | 同前缀一致性 | 用途 |
|---|---|---|---|---|
| B0 | 否 | 否 | 否 | 新预算下的原算法参考 |
| B1 | 是 | 否 | 否 | 检验患者风险目标 |
| B2 | 否 | 是 | 否 | 检验终末直接梯度路径 |
| B3 | 否 | 否 | 是 | 检验随机预测稳定性 |
| B4 | 是 | 是 | 是 | 推荐组合候选 |

B0 仍使用统一的参考 batch 分母与新调度，以免把尾批归约差异当成患者权重收益。若组合改善而单项结果难解释，再补 B4 去掉某项的消融，不能根据组合提升宣称每项都有效。

建议先在训练患者内部一个固定开发划分用 seed17 筛查实现和机制；此结果只能筛选。冻结保留的方案后，再在三个患者级内部划分复核稳定性；配置确定后，按完整原训练集和原102人开发验证集，固定 / 动态各 seed17/43/71 报告最终开发结果。每个正式比较都配对使用相同划分、种子和选模规则。

若要判断世界预测本身的贡献，再在同一改进训练协议下比较 `direct`、`copy_gated`、`gated`：direct 仍保留 A+B，是联合 direct 读出；copy_gated 给同容量未来头复制的已观察锚点；gated 给其预测终点。只有预测版优于匹配的 copy/direct，才能支持未来预测对 pCR 有用。单独的 free/copy latent 优势不能代替该对照。

## 数据划分与归一化

内部筛选建议从原764名训练患者中，按患者和 pCR 分层固定80% / 20%开发划分；一个患者所有前缀只能在同一侧。内部开发验证不再作为训练数据参与该阶段拟合。原102人已反复选模，只能称开发验证集；它既不是独立测试集，也不应继续用来逐项调超参数。

特别注意：现影像缓存已按原764名训练患者的总体前景均值 / 标准差归一化。因此严格内部划分不能简单更换 manifest 的 split 而直接宣称无折内信息使用。必须从上游未归一化 ROI 及可靠前景 / padding mask，按每次内部训练侧重建归一化与缓存；临床年龄标准化也只拟合该训练侧。不能仅凭数值等于0推断哪些体素属于背景，因为真实前景归一化后也可能等于0。无法重建时，明确标注该内部筛选存在预处理统计共享的限制，不作严格折外泛化证明。

最终若在完整原764训练集上重新训练，则原缓存的训练拟合范围与这一训练划分一致。独立泛化结论仍需新测试患者，或从头进行包含归一化、预训练、选模在内的嵌套患者级交叉验证。

## 记录什么、怎样判定有效

主指标为患者等权 NLL，同时报告各阶段 AUC、AP、Brier 和三种子变动。可以预先把相对新协议 B0 的平均 NLL 至少下降0.01设为工程筛选目标；该阈值不是统计显著性，也不是成功保证。要求改善没有完全依赖单一种子，且排序 / 校准指标没有明显恶化。102人验证上的 bootstrap 仍条件于拟合与选择过程，不能当作独立测试证明。

辅助记录：

- 每次评估同时对固定训练子集做 eval-mode、无随机遮蔽的 pCR 评估；训练侧与验证侧都用相同患者等权定义，便于比较实际风险差距。完整训练 eval 成本可由预先固定的患者子集控制，不使用验证结果选该子集。
- 概率分布、logit绝对值、Brier、门控均值和分支 NLL，判断是否出现错误但过度自信的预测。
- 以低频独立探针记录 A/B/C 在 encoder/fusion/world 参数组上的梯度范数、夹角与 clip 比例；不得让探针改变正式训练 RNG 或执行额外 optimizer/EMA 更新。标量 loss 大小不能证明梯度冲突。
- 在同一 checkpoint / 同一教师坐标下比较 free 与 copy；跨 epoch 原始 JEPA 不作为固定空间的未来预测改善证据。
- best 后验证退化幅度、更新数、样本展示次数、GPU时间和峰值显存；一致性多一次分类前向，不能把相同 update 当成相同算力成本。

如果训练和验证同时较差，或 gap 变小但 best NLL 更差，应判断为欠拟合 / 正则过强，不能称解决过拟合。若改进仍弱于旧主线，旧模型继续作为临床预测参考；不以更复杂网络替代结果证据。
