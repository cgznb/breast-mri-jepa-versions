A self-contained, source-only three-phase MRI research workflow and non-destructive integration package for `cgznb/symm-fm` at commit `92265d3b1749ae3b686f2089843c49da129fd4d2`.

This is not a mirror of every historical upstream workflow. It contains the complete new workflow, its data/model/training/inference/evaluation code, and tests. It does not contain patient data, clinically validated weights or claimed clinical performance. Third-party licenses, including non-commercial terms, are retained in `licenses/`.
